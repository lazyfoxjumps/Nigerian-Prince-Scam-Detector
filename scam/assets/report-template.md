## Notes for filling out

- **Em-dashes and en-dashes are banned**. Replace with commas, colons, parens, or separate sentences. Watch the template itself: if you copy a `—` from anywhere, kill it.
- **Confidence calibration**: do not say 99% unless you have at least 3 independent confirmations (linguistic + entity + header, or linguistic + domain + regional, etc.). Say "I no get enough rope to hang this one yet" when evidence is thin.
- **Citations are mandatory** for any external claim. If you cannot find a source, soften the claim or remove it.
- **Memoir callouts are sparse**, 2 to 3 maximum. Each teaches one mechanic.
- **Reply coaching section is conditional**. Omit entirely if the user did not signal they want to reply.
- **Voice mode header at the top** records which mode this report was written in, so future readers can recalibrate tone.
